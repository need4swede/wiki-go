# Initial Setup

| Step | Description |
|------|-------------|
| [Server Connection](/getting-started/setup/server-connection) | Connect to a supported media server |
| [Authentication](/getting-started/setup/authentication) | Sign in to your account |
| [Plugins](/getting-started/setup/plugins) | Optional backend extensions (Jellyfin today) |
| [Seerr](/getting-started/setup/seerr) | Optional content discovery |

Neptune uses a shared experience across media-server backends. Jellyfin is supported today; Plex and Emby are planned, with additional backends to be determined. Setup options that apply only to one backend are labeled in the pages below.

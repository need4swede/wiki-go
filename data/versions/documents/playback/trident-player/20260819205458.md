## How Trident Handles Media

### Direct Play

Trident plays supported files directly from your media server without conversion.
The [Video Codecs & Containers](/playback/trident-player/codecs), [Audio](/playback/trident-player/audio), and [Subtitles](/playback/trident-player/subtitles) pages are the authoritative format references.

### Transcoding

When direct play is not practical, a compatible backend can transcode the file instead.
The backend re-encodes the stream on the fly to fit your chosen bitrate limit.

Configure this in **Settings > Playback > Playback Mode**, or change quality mid-playback using the [Playback Menu](/playback/playback-menu).
Quality changes restart the stream in place without losing your position.

## During Playback

### Tracks and Playback Options

Switch audio or subtitle tracks mid-playback from the [Playback Menu](/playback/playback-menu).
Track changes happen in place without restarting the video stream.
The Playback Menu also provides quality, chapters, de-interlacing, and stream information for the current item.

### Caching

Playback use a temporary disk cache. This caching keeps a bounded working window for the current playback session, which supports read-ahead and instant seeking within cached portions.

**Full Video Caching**, when enabled via **Settings > Playback > Advanced**, continues caching toward the end of the file while playback is paused. Neptune uses as much safe storage as is currently available and, when necessary, removes the oldest already-watched cache blocks to make room for new video farther ahead.

The cache is temporary, not an offline download.
Use [Downloads](/browsing/home-screen/downloads) for persistent offline viewing.

## Platform Behavior

### iPhone and iPad

Leaving Neptune releases the extended cache back to the ordinary playback window.

Returning to the same paused session resumes caching.

A normal player close removes the temporary cache immediately, and Neptune cleans up an orphan on its next launch if an abrupt termination prevented normal close.

Trident also powers [Picture in Picture and Background Playback](/ios/playback).

Picture in Picture uses the system video window, while background-only sessions continue audio and rejoin the video when Neptune returns to the foreground.

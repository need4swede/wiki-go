# Item Details

When you select content, Neptune displays detailed information and actions.



## In This Section

| Page | Description |
|------|-------------|
| [Movies](/browsing/item-details/movies) | Movie pages, quality badges, cast |
| [TV Shows](/browsing/item-details/tv-shows) | Series, seasons, episodes, episode finder |
| [Extras](/browsing/item-details/extras) | Special features, trailers, behind-the-scenes |
| [People](/browsing/item-details/people) | Actor, director, and crew detail pages |



## Common Elements

All detail views display:

- **Backdrop**: Full-screen background image
- **Logo/Title**: Official logo or text
- **Metadata**: Year, runtime, rating, genres
- **Overview**: Plot summary
- **Play button**: Start or resume playback



## Action Pill

A row of secondary actions sits below the Play button. Available actions vary by item type:

| Action | What It Does |
|--------|--------------|
| **Pin** | Pin the item as a [shortcut](/library/shortcuts) on the Library tab |
| **Trailer** | Play the trailer (when available) |
| **Mark Watched** | Toggle played status |
| **Favorite** | Toggle favorite status |
| **Shuffle** | (Series only) Toggle shuffle mode for the show |
| **Spoiler Protection** | (Series only) Hide episode thumbnails and overviews until played |
| **Episode Finder** | (Series only) Find an episode by describing what happens in it |
| **Refresh AI** | (When semantic search is on) Re-analyze the item for semantic tags |
| **Refresh Metadata** | Pull fresh metadata from the server |

Admin users also see an option to edit images directly from the detail view.

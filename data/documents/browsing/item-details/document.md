# Item Details

When you select content, Neptune displays detailed information and actions.



## In This Section

| Page | Description |
|------|-------------|
| [Movies](/browsing/item-details/movies) | Movie pages, quality badges, cast |
| [TV Shows](/browsing/item-details/tv-shows) | Series, seasons, episodes, episode finder |
| [Extras](/browsing/item-details/extras) | Special features, trailers, behind-the-scenes |
| [People](/browsing/item-details/people) | Actor, director, and crew detail pages |



## Layouts

Detail pages render in one of three layouts: **Detailed**, **Immersive**, or **Minimal**. The data is identical; only the composition changes. Pick your preference during onboarding or in **Settings > User Preferences > Appearance > Layouts**. See [Item Detail Layouts](/personalization/item-detail-layouts) for the full breakdown.



## Common Elements

All detail views display:

- **Backdrop**: Full-screen background image
- **Logo/Title**: Official logo or text
- **Metadata**: Year, community and critic ratings, content rating, runtime
- **Overview**: Plot summary
- **Play button**: Start or resume playback

If an item has several versions (say a 4K remux and a 1080p encode), the Play button offers a version picker. Two versions slide out as an inline pill; three or more open a **Choose Version** sheet with quality chips for resolution, HDR format, and audio. See [Conductor](/playback/conductor) for how Neptune can pick automatically.



## Action Pill

A row of secondary actions sits below the Play button. Available actions vary by item type:

| Action | What It Does |
|--------|--------------|
| **Pin** | Add the item to [Pins](/library/shortcuts) on the Library tab |
| **Trailer** | Play a trailer when available. Prefers local trailer files, otherwise opens YouTube (see [Extras](/browsing/item-details/extras)) |
| **Mark Played** | Toggle played status |
| **Add Favorite** | Toggle favorite status |
| **Shuffle** | (Series) Play a random episode with [shuffle mode](/browsing/item-details/tv-shows) |
| **Spoilers** | (Series) Hide episode thumbnails and overviews until played |
| **Find Episode** | (Series) Find an episode by describing what happens in it. Needs a language model |
| **Request** | (Seerr) Request missing seasons or related content |
| **Edit Images** | (Admins) Change the poster, backdrop, logo, and other artwork |
| **Refresh Metadata** | (Admins) Pull fresh metadata from the server |



## Insights

Select the description card on a movie or show page—or the biography on a person page—to open **Insights**: context, trivia, themes, career patterns, collaborators, and watch suggestions generated by your configured language model. See [Title Insights](/neptune-ai/title-insights) and [Person Insights](/neptune-ai/person-insights) for details.

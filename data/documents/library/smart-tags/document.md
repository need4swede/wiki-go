# Smart Tags

Browse your library by theme, setting, and mood instead of genre.
Smart Tags are the same semantic tags that power [Semantic Search](/search/semantic-search), turned into a browsing surface.

Open them from **Browse by > Tags** on the Library tab.

## Browsing Tags

Three gateways organize the catalog:

| Gateway | Examples |
|---------|----------|
| **Themes** | Time travel, heist, revenge, coming of age |
| **Settings** | Space, dystopia, small town, high seas |
| **Moods** | Feel-good, dark, suspenseful, slow burn |

Select any tag to see everything in your library that matches.
Tags can be added to [Library Pins](/library/shortcuts) for one-tap access later.

## Surprise Me

A slot machine for movie night.
**Surprise Me** spins a random combination of tags and shows you how many titles match.

- Press **Spin** to roll a new combination
- Lock a reel to keep a tag you like and re-spin the rest
- Select **View Results** when the combination sounds right

Good for breaking a household deadlock: nobody picked it, the machine did.

## Mix & Match

Build a tag combination by hand.
**Mix & Match** lets you stack tags and narrows the results as you go, only offering tags that still have matches with your current selection.
The match count updates live, and **View Results** opens the grid.

**Clear All** starts you over.

## Where Tags Come From

Tags come from Neptune's curated semantic catalog, which covers popular and classic titles and updates over the air.
Coverage depends on your library; niche or very new items may not have tags yet.
See [Semantic Search](/search/semantic-search) for details.

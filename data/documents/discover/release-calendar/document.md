# Release Calendar

A chronological view of upcoming movies and television, built from Seerr's release data. Use it to see what is arriving soon without mixing dates into popularity-ranked rows.



## Opening the Calendar

Select the **Release Calendar** banner on Discover. The calendar combines upcoming movies and TV shows, removes past dates, and groups the remaining titles into:

1. **This Week**
2. **Next Week**
3. **Later This Month**
4. Future months in chronological order

Within each group, titles are sorted by release or first-air date.



## Calendar Cards

Each card shows the title's release context and uses the same availability/request status as the rest of Discover. Select a card to open its detail page, where you can:

- Play it if it is already available
- Review an existing request
- Request it before release when your Seerr setup allows
- Choose seasons for a television request



## Language Filtering

The calendar respects **Settings > Seerr > Seerr Preferences > Language Preferences**. If a language filter is active, both its movie and TV sources are narrowed before the dates are grouped.



## Empty Calendar

If Seerr returns no future titles for the active language and account, Neptune shows **No upcoming releases found**. This does not mean your request history or Coming Soon row was erased; those are separate request-based views.



## Release Calendar vs. Coming Soon

| View | Source | Purpose |
|------|--------|---------|
| **Release Calendar** | Seerr's broader upcoming catalog | Explore future movies and shows |
| [Coming Soon](/browsing/home-screen/coming-soon) | Your requests and tracked automation | Follow content already on its way to your server |

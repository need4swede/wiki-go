# Home Settings

Control what the Home screen shows and how the app navigates. Four tabs: **Library**, **Navigation**, **Spotlight**, and **Sections**.



## Library

How library content presents itself on Home:

| Setting | Description |
|---------|-------------|
| **Libraries** | Reorder or hide libraries on the home screen |
| **Group Movies into Collections** | Fold movies into their collections on the Movies tab: Off, Auto, or On |
| **Keep Sorting Preference** | Remember your last sort in browse views |
| **Display Titles / Display Year / Display Card Labels** | What text appears under library cards |



## Navigation

The tab bar and app navigation behavior:

| Setting | Description |
|---------|-------------|
| **Customize Navigation Bar** | Reorder or hide tabs. Settings and Search stay at the edges |
| **Movies Tab Label** | Movies, Films, or Cinema |
| **Shows Tab Label** | Shows, TV, or Series |
| **Highlight Navigation Bar / Highlight Library Picker** | Focus highlight styles, with a Small or Large size |
| **Always Start From Top** | Scroll to the top when changing tabs |
| **Navigation Bar Scroll Behavior** | Show, Hide, or Collapse the bar while scrolling |
| **Exit App on Back Press** | Never, from the Default Tab, or Always |

See [Navigation](/browsing/navigation) for how these play out.

Movies, Shows, and Music are hidden by default. Movies and Shows reuse the Home sections with type filtering. Music has its own Spotlight, Continue Watching, Recently Added, and Artists layout; long-press the Music tab and choose **Edit Music** to customize it.



## Spotlight

| Setting | Description |
|---------|-------------|
| **Spotlight Limit** | Carousel size, 4 to 12 items |
| **Direct Navigation** | Skip the fullscreen gallery and open spotlight items directly |



## Sections

Row limits and behavior for the Home screen sections:

| Setting | Description |
|---------|-------------|
| **Continue Watching** | Row limit |
| **Next Up** | Row limit |
| **Next Up Cutoff** | Drop shows untouched for 30, 90, 180, or 365 days, or never |
| **Recently Added** | Row limit |
| **Combine Recently Added** | One merged row instead of per-library rows |
| **Recommended** | Row limit |
| **Include Seerr in Recommendations** | Blend requestable titles into Recommended |
| **New Release Threshold** | The [New Releases](/browsing/home-screen/new-releases) window, 7 to 90 days |

Section order and visibility are edited on the Home screen itself: long-press the tab and pick **Edit Home Screen**.

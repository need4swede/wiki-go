# Home Settings

Control what the Home screen shows, how the app navigates, and what appears while Home is loading.
On Apple TV, settings are grouped into categories in the left rail. iPhone and iPad use sections in a settings list.

## Loading Screen

| Setting | Description |
| --- | --- |
| **Display hints** | Show or hide launch messages |
| **Use library artwork** | Put a cached poster or backdrop behind the loading sequence |
| **Artwork source** | Choose Spotlight, Continue, Favorites, Recently Added, or Random |

Posters are used in portrait orientations and backdrops in landscape.

Featuring library artwork during loading screens is exclusive to [Neptune Pro](/neptune-pro) users.
See [Cinematic Loading Screens](/neptune-pro/loading-screens) for source selection, orientation behavior, and how the independent launch artwork reserve works.

## Library

How library content presents itself on Home:

| Setting | Description |
| --- | --- |
| **Libraries** | Reorder or hide libraries on the home screen |
| **Group Movies into Collections** | Fold movies into their collections on the Movies tab: Off, Auto, or On |
| **Keep Sorting Preference** | Remember your last sort in browse views |
| **Display Titles / Display Year / Display Card Labels** | What text appears under library cards |

## Navigation

Page visibility, labels, and navigation behavior:

| Setting | Description |
| --- | --- |
| **Customize Navigation Bar** | Choose page order, visibility, and the starting page |
| **Impatient Mode** | [Play or resume playable cards immediately instead of opening Item Detail first](#impatient-mode) |
| **Limit to Continue Watching / Next-Up** | [Apply Impatient Mode only to those two continuation sections](#impatient-mode) |
| **Movies Tab Label** | Movies, Films, or Cinema |
| **Shows Tab Label** | Shows, TV, or Series |
| **Highlight Library Picker** | Highlight the focused library |
| **Highlight Size** | Small or Large library-picker highlight |
| **Always Start From Top** | Scroll to the top when changing tabs |
| **Exit App on Back Press** | Never, from the Default Tab, or Always |

On Apple TV, Compass opens from the top-right pill.
Its Navigation row has its own shortcut order under **Settings > Account > Compass**.
See [Navigation](/browsing/navigation) for the controls.

Movies, Shows, and Music are hidden by default.
Movies and Shows reuse the Home sections with type filtering.
Music has its own Spotlight, Continue Watching, Recently Added, and Artists layout.

## Impatient Mode

When **Impatient Mode** is enabled, selecting a playable card starts or resumes playback immediately instead of opening Item Detail first.

Turn it on under **Settings > Home > Navigation**.
The setting applies to playable cards throughout Home and its content tabs unless you enable [**Limit to Continue Watching / Next-Up**](#impatient-mode).

The limiter appears only after Impatient Mode is enabled.
With it enabled, Continue Watching and Next Up cards start playback immediately and resume saved progress when one exists, while other cards keep their normal detail-first behavior.
Spotlight's Play or Resume button always starts playback, and its Details button always opens the detail page.
Use long presses to bring up additional options.

## Spotlight

| Setting | Description |
| --- | --- |
| **Spotlight Content** | Show or hide content types and choose Automatic or Custom priority |
| **Spotlight Limit** | Maximum items in the rotation, default 8. Apple TV offers 4, 6, 8, 10, or 12; iPhone and iPad offer 4, 8, or 12 |
| **Immersive Spotlight** | Apple TV only. On fades between the full-screen header and the rows; Off lets the page scroll with the first row peeking below |

Custom priority gives types near the top more space in the rotation while keeping a mix of enabled types.
At least one content type stays on.
Music's Spotlight is separate from these content-type choices.

See [Spotlight](/browsing/home-screen/spotlight) for controls, placement, content selection, and how Immersive Spotlight works.

## Sections

Row limits and behavior for the Home screen sections:

| Setting | Description |
| --- | --- |
| **Continue Watching** | Row limit |
| **Next Up** | Row limit |
| **Next Up Cutoff** | Drop shows untouched for 30, 90, 180, or 365 days, or never |
| **Recently Added** | Row limit |
| **Combine Recently Added** | One merged row instead of per-library rows |
| **Recommended** | Row limit |
| **Include Seerr in Recommendations** | Blend requestable titles into Recommended |
| **New Release Threshold** | The [New Releases](/browsing/home-screen/new-releases) window, 7 to 90 days |

On Apple TV, select **Customize Home Screen Layout** in this category to reorder or hide sections and add [Custom Sections](/browsing/home-screen/custom-sections).
On iPhone and iPad, open Home's **Options** from the navigation pill, then choose **Edit Layout**.
